# Contributing

Contributions must preserve local-first operation, zero mandatory SaaS cost, medical-safety review boundaries, and framework-independent exports.

1. Create a `codex/<topic>` or ordinary feature branch.
2. Work only with synthetic records.
3. Add tests for writes, audit behavior, search/index impact, export/import, and backup compatibility.
4. Run Python tests, frontend tests/lint/build, and the staged privacy guard.
5. Explain data migration, rollback, privacy, and medical-safety effects in the pull request.

Do not submit real prescriptions, screenshots, names, OCR text, voice files, database fragments, backup archives, secrets, or production paths. Security issues should be reported privately with synthetic reproduction data.
